## 🚀 실행 방법

```bash
npm install
cp .env.example .env.local
#   VITE_API_BASE_URL=/api
#   VITE_API_PROXY_TARGET=http://localhost:8000   (백엔드 주소)
npm run dev   # → http://localhost:5173
```

> 🎙️ 음성 인식은 Web Speech API를 사용하므로 **Chrome 또는 Edge**를 권장합니다.
